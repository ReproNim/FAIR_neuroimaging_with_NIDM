# FAIR neuroimaging with the Neuroimaging Data Model and PyNIDM
![Zenodo doi badge](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.15850461-blue.svg)

## Description

How do I produce a neuroimaging study which is FAIR: Findable, Accessible, Interoperable, and Reusable? Here we describe the Neuroimaging Data Model (NIDM), a knowledge graph-based methodology for recording all aspects of a neuroimaging study. Using an example analysis of brain size cf. age, we walk through the steps to track, organize and characterize your raw neuroimaging data, annotate derived data and share files publicly using FAIR principles.
